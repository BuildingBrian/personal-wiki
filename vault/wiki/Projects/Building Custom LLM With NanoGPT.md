# Building Custom LLM With NanoGPT

This document details the process of building a custom Large Language Model using nanoGPT. The author trained nanoGPT twice on different datasets to extend its capabilities.

## Key details

- The author trained Andrej Karpathy's nanoGPT twice on an Intel MacBook's CPU.
- The first training run used the supplied classroom corpus.
- The second training run included the author's own synthetic teaching files for three extension skills.
- Both training runs used the same settings, seed, split rule, and evaluation panels.
- The same unchanged 48-case language evaluation suite was used before and after training.
